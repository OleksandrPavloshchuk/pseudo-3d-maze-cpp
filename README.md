# pseudo-3d-maze-cpp

tutorial implementation of classical ray casting algorithm in C++ and SDL3

## Scripts in `script`

| File      | Purpose                     |
| --------- | --------------------------- |
| `cmakew`  | run cmake on current system |
| `configw` | configure project for build |
| `buildw`  | build project               |
| `runw`    | run application             |

## Install libraries on Ubuntu 24

```script
sudo apt update

sudo apt install \
    libx11-dev \
    libxext-dev \
    libxrandr-dev \
    libxcursor-dev \
    libxfixes-dev \
    libxi-dev \
    libxss-dev \
    libxkbcommon-dev \
    libwayland-dev \
    libwayland-egl1 \
    libwayland-cursor0 \
    libwayland-bin \
    wayland-protocols \
    libdecor-0-dev \
    pkg-config
```
